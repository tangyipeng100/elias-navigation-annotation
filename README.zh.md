ELIAS 按区域判断 → 开放终点观察 → 本地规范词检索 → 双锚点终点对齐 → 双语生成 → 一致性接受门组织证据。场景先验提供命名与空间参考，绕过开放终点观察；前向锚点和停靠锚点分别描述面向什么、停在哪里。标注工作台支持证据检查与修改。

当前评价涵盖 40 个样本组、120 个冻结候选。独立 GPT-5.5 方法盲评中，渲染完整轨迹的关键错误率由 95% 降至 25%，可直接使用率由 5% 升至 75%；真机完整轨迹由 100% 降至 20%、由 0% 升至 80%。这些是初步模型评价结果，不是人工金标准，也不是导航成功率；没有下游导航效果、人工节时或多人一致性实验。
