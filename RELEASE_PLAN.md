# Release plan

## Available now

- Public project page and its HTML/CSS/JavaScript source.
- Selected method, workbench, result, and qualitative figures.
- Explicit coming-soon status for the paper and research implementation.

## After paper acceptance and a release review

- Confirm publication metadata and the public paper version.
- Organize the annotation-pipeline implementation and setup documentation.
- Document model/provider dependencies and experiment reproduction limits.
- Review credentials, local paths, internal identifiers, and sensitive scene material before release.
- Decide code and asset licenses; clarify whether any data can be distributed.
- Publish a versioned implementation with an accurate citation and limitations.

No acceptance-dependent task runs automatically from this repository. No raw datasets, credentials, request logs, or research implementation are part of the initial public commit.
